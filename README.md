# Liquid Glass Music Player — Android 16 (API 36)

Премиальный офлайн-плеер скачанных треков для **Android 16** в улучшенной эстетике **Liquid Glass 2.0** с аппаратным **Motion Blur**, живым адаптивным фоном под обложку трека, графиками статистики прослушиваний, загрузкой **собственных шрифтов (.ttf / .otf)** и поддержкой **120 Гц**.

## Главные возможности

- **Плеер локальной музыки (ExoPlayer / Media3)**:
  - Автоматическое сканирование всех скачанных песен (`MP3`, `FLAC`, `WAV`, `M4A`, `OGG`, `OPUS`) через `MediaStore`.
  - Поиск, сортировка, избранное, очередь воспроизведения, случайный порядок (Shuffle), повтор (Repeat One / All), скорость воспроизведения (`0.5x – 2.0x`), таймер сна.
  - Встроенный **5-полосный эквалайзер и Bass Boost** (через `android.media.audiofx`).
- **Liquid Glass 2.0 & Motion Blur**:
  - Динамический **Aurora Mesh** фон, который в реальном времени подстраивает цвета под обложку текущего трека (`Palette API`).
  - Аппаратный **Motion Blur** (`RenderEffect`) при свайпах вкладок, раскрытии полноэкранного плеера и взаимодействии с кнопками.
  - Живой аудио-визуализатор (волны / спектр / пульсирующая сфера) и плавная пружинная физика.
- **Статистика и графики прослушиваний**:
  - Интерактивный стеклянный график прослушиваний за 7 дней (минуты по дням).
  - Общее время прослушивания, количество треков, серия дней (Streak), топ любимых песен и исполнителей.
- **120 Гц и сверхплавность в настройках**:
  - Выбор частоты обновления экрана прямо в настройках: **Авто / 60 Гц / 90 Гц / 120 Гц / Максимум устройства** (через `Display.Mode` и `preferredDisplayModeId`).
  - Отображение реальных поддерживаемых частот дисплея и настройка плавности пружинных анимаций.
- **Свой шрифт и глубокая кастомизация**:
  - Импорт любого файла шрифта **`.ttf` / `.otf`** с устройства с мгновенным применением ко всему интерфейсу + встроенные шрифты.
  - 8 тем оформления (включая динамическую тему от обложки трека и Material You), ползунки плотности стекла, размытия, бликов, скруглений, Motion Blur, масштаба шрифта и скорости анимаций.

## Сборка APK

### Через GitHub Actions (без Android Studio)
1. Загрузите содержимое архива в новый репозиторий на GitHub.
2. Перейдите во вкладку **Actions** → workflow **Android CI Build** соберёт `app-debug.apk`.
3. Скачайте готовый APK из раздела **Artifacts**.

### Через Android Studio
1. Откройте папку `LiquidGlassPlayer` в Android Studio (Android SDK 36, JDK 17).
2. Дождитесь синхронизации Gradle и запустите на устройстве Android 12–16.
